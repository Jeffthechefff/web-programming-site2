Web History Timeline

1989 - The World Wide Web Is Proposed

In March 1989, British scientist Tim Berners-Lee proposed a system for sharing information between researchers at CERN and other institutions around the world. His idea combined computers, networks, and hypertext into a system where documents could be connected through links. This proposal became the foundation of the World Wide Web.

www.home.cern/science/computing/the-birth-of-the-web/short-history-web/

1990 - The First Web Browser and Web Server Are Created

By the end of 1990, Tim Berners-Lee had created the first Web browser and the first Web server at CERN. The browser was called WorldWideWeb, and the first website was hosted at info.cern.ch on a NeXT computer. This transformed the original proposal into a working system.

www.home.cern/science/computing/the-birth-of-the-web/short-history-web/

1991 - The World Wide Web Becomes Available Beyond CERN

In 1991, Berners-Lee released the Web software, including the browser, Web server software, and a library for developers. In August of that year, he announced the project on Internet newsgroups, allowing people outside CERN to learn about the Web and begin developing for it. The first Web server in the United States was also established at the Stanford Linear Accelerator Center in December 1991.

www.home.cern/science/computing/the-birth-of-the-web/short-history-web/

1992 - The Line-Mode Browser Makes the Web More Accessible

The line-mode browser was developed to make the Web usable on computers other than the NeXT systems used by Berners-Lee. It could run on different types of computers and was easier to install than the original browser. This helped make the Web accessible to a wider group of users and developers.

www.home.cern/science/computing/the-birth-of-the-web/

1993 - Mosaic Browser Is Released

In early 1993, the National Center for Supercomputing Applications (NCSA) released the Mosaic Web browser. Mosaic provided a more user-friendly graphical interface and was subsequently made available for PCs and Macintosh computers. Its ease of use helped accelerate the spread of the Web beyond the scientific and academic communities.

www.ncsa.illinois.edu/about/history/

1993 - CERN Makes the Web Free to Use

On 30 April 1993, CERN made the World Wide Web software available on a royalty-free basis and later placed it in the public domain. This meant that people and organizations could use the technology without having to pay licensing fees to CERN. Making the Web freely available helped it spread rapidly around the world.

www.home.cern/science/computing/30-years-of-a-free-and-open-web/

1994 - The World Wide Web Consortium (W3C) Is Founded

In October 1994, Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT, in collaboration with CERN and with support from DARPA and the European Commission. The organization was created to help coordinate the development of common Web standards as the technology rapidly expanded. These standards helped different browsers, computers, and Web technologies work together.

www.w3.org/about/history/

1994 - The Web Begins Expanding Rapidly

By 1994, the Web was experiencing rapid growth and attracting increasing attention from businesses, researchers, and the general public. The first International World Wide Web Conference was held at CERN in May, bringing together hundreds of Web users and developers. By the end of the year, CERN reported approximately 10,000 Web servers and 10 million users.

www.home.cern/science/computing/the-birth-of-the-web/short-history-web/

1995 - The Web Expands Internationally

In 1995, the Web continued to expand as organizations around the world began adopting Web technologies. INRIA in France became the first European host of the W3C, followed by Keio University in Japan in 1996. This helped establish an international structure for developing and maintaining Web standards.

www.w3.org/about/history/

1998 - CSS Becomes a Web Standard

Cascading Style Sheets (CSS) became an important part of Web development during the late 1990s, allowing developers to separate the presentation and visual design of Web pages from their HTML structure. This made it easier to create consistent layouts and styles across multiple pages. The development of Web standards through W3C helped CSS become a major technology used to design websites.

www.w3.org/standards/

2004 - The Web Becomes More Interactive

During the early 2000s, Web technologies increasingly allowed users to interact with websites rather than simply read static pages. This period is commonly associated with Web 2.0, which included user-generated content, social networking, blogs, wikis, and interactive Web applications. The Web increasingly became a platform where users could both consume and create content.

www.w3.org/

2007 - Mobile Web Access Grows

The introduction of modern smartphones helped change how people accessed the Web. Mobile devices increasingly allowed users to browse websites and use online services without being connected to a traditional desktop computer. This contributed to the Web becoming accessible from a much wider range of locations and devices.

www.w3.org/

2010s - The Web Becomes a Platform for Modern Applications

During the 2010s, Web technologies developed beyond traditional documents and simple websites. Web applications increasingly provided functions that previously required dedicated desktop software, while improvements in HTML, CSS, JavaScript, browsers, and mobile devices made the Web more interactive and capable. The Web became an important platform for communication, education, entertainment, commerce, and online services.

www.w3.org/

2020s - The Web Continues to Evolve

Today, the Web supports increasingly sophisticated applications and operates across computers, smartphones, tablets, and many other connected devices. Organizations such as W3C continue developing open Web standards intended to maintain interoperability and accessibility. The Web has evolved from a system created for sharing scientific information into a global platform used for communication, business, education, entertainment, and applications.

www.w3.org/about/
