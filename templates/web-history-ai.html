History of the World Wide Web

A chronological timeline showing the major events that shaped the development of the World Wide Web.

Navigation

Internet History | Web History

Introduction

The World Wide Web is a system that allows information to be published and connected through hyperlinks. It was developed at CERN by Tim Berners-Lee and gradually evolved from a research project into a technology used around the world.

The Web should not be confused with the Internet. The Internet provides the underlying network, while the Web is one of the services that operates using that network.

Reference: https://home.cern/science/computing/the-birth-of-the-web/

1980 — ENQUIRE

In 1980, while working as a consultant at CERN, Tim Berners-Lee created a program called "ENQUIRE".

The program allowed information to be connected through links between different pieces of information. Although it was not the World Wide Web, its ideas influenced Berners-Lee's later work on a global hypertext system.

Reference: https://www.w3.org/History.html

1989 — The Web Is Proposed

In March 1989, Tim Berners-Lee wrote a proposal at CERN called "Information Management: A Proposal."

The proposal described a system that could help researchers share information more effectively. It introduced ideas that later became part of the World Wide Web.

Reference: https://www.w3.org/webat25/about/history

1990 — Development of the Web Begins

During 1990, Tim Berners-Lee began developing the first practical version of the Web at CERN.

He worked on a browser and editor called "WorldWideWeb", created the first Web server, and developed the technologies needed for Web communication.

By the end of 1990, the first Web server and browser were operating at CERN.

Reference: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/

1990 — HTML, HTTP and URLs

During the early development of the Web, Tim Berners-Lee created important technologies that became the foundation of Web pages and Web communication.

These included HTML for structuring documents, HTTP for communication between Web clients and servers, and URLs for identifying resources on the Web.

Reference: https://www.w3.org/about/history/

1991 — The Web Is Released

In 1991, Berners-Lee released the World Wide Web software. It included a browser, Web server software, and a library that developers could use.

In August 1991, information about the Web software was posted on Internet newsgroups, allowing people outside CERN to learn about the project.

Reference: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/

1991 — First Web Server Outside Europe

In December 1991, the first Web server outside Europe was established at the Stanford Linear Accelerator Center (SLAC) in California.

This was an important step in expanding the Web beyond CERN and Europe.

Reference: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/

1992 — More Web Browsers Appear

During 1992, additional Web browsers were being developed. Browsers such as Viola became available and provided alternatives to the original browser created at CERN.

The increasing number of browsers made the Web accessible through different computer systems.

Reference: https://www.w3.org/webat25/about/history

1993 — Mosaic Browser

In February 1993, the National Center for Supercomputing Applications (NCSA) released the first alpha version of Mosaic for X.

Mosaic became an important browser in the early history of the Web and helped make Web browsing easier for a wider audience.

Reference: https://www.w3.org/History.html

1993 — CERN Makes the Web Free to Use

On April 30, 1993, CERN announced that the Web technology could be freely used by anyone without fees being paid to CERN.

Making the technology freely available removed an important barrier to its adoption and helped the Web spread rapidly.

Reference: https://home.cern/science/computing/the-birth-of-the-web/where-web-was-born/

1994 — The Web Becomes International

In May 1994, the first International World Wide Web Conference was held at CERN in Geneva.

The conference brought together people interested in the development of the Web and demonstrated how quickly the technology was attracting international attention.

Reference: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/

1994 — Creation of the W3C

In October 1994, Tim Berners-Lee founded the World Wide Web Consortium, commonly known as W3C.

The organization was created to coordinate the development of Web standards and encourage an interoperable Web.

W3C was initially hosted at the Massachusetts Institute of Technology in collaboration with CERN, with support from other organizations.

Reference: https://www.w3.org/about/history/

1994 — Netscape

In 1994, Marc Andreessen and colleagues from NCSA created Mosaic Communications Corporation, which later became Netscape Communications Corporation.

Netscape Navigator became one of the important Web browsers during the rapid growth of the Web in the 1990s.

Reference: https://www.w3.org/wiki/The_history_of_the_Web

1995 — Internet Explorer

In August 1995, Microsoft released Internet Explorer 1.0. The browser was based on technology licensed from Spyglass, which had commercialized NCSA Mosaic technology.

The appearance of Internet Explorer contributed to increased competition between major Web browsers.

Reference: https://www.w3.org/wiki/The_history_of_the_Web

1996 — CSS1

Cascading Style Sheets, commonly known as CSS, became an important technology for controlling the presentation of Web documents.

On December 17, 1996, CSS Level 1 became a W3C Recommendation. CSS allowed Web authors to separate document structure from visual presentation.

Reference: https://www.w3.org/press-releases/1996/css1-rec/

1997 — HTML 3.2

In January 1997, HTML 3.2 became the first W3C Recommendation for HTML.

This helped establish a more consistent set of HTML features that Web developers and browser manufacturers could support.

Reference: https://www.w3.org/2005/01/timelines/description

1997 — Dynamic Web Technologies

During the late 1990s, Web technologies increasingly supported interactive and dynamic content. JavaScript, server-side technologies, and other Web development tools allowed websites to become more than collections of static documents.

These technologies contributed to the development of Web applications and more interactive websites.

Reference: https://www.w3.org/wiki/The_web_standards_model_-_HTML_CSS_and_JavaScript

1998 — HTML 4.0

HTML 4.0 became a W3C Recommendation in April 1998.

The specification expanded HTML's capabilities, including support for multimedia, scripting, style sheets, improved accessibility, and internationalization.

Reference: https://www.w3.org/TR/1998/REC-html40-19980424/

2000s — The Web Becomes More Interactive

During the 2000s, websites increasingly developed into interactive applications rather than simply displaying documents.

Technologies such as JavaScript, improved browsers, server-side programming, and databases allowed developers to create increasingly interactive online services.

Reference: https://www.w3.org/wiki/The_history_of_the_Web

2004 — Web 2.0

During the 2000s, the term "Web 2.0" became associated with websites that emphasized user participation, interaction, and content created by users.

This period saw the growth of blogs, social networking, collaborative websites, and other interactive Web services.

Reference: https://www.w3.org/wiki/The_history_of_the_Web

2010s — Responsive and Mobile Web Development

As smartphones and tablets became increasingly important, Web developers needed websites to work across different screen sizes and devices.

Responsive Web design became an important approach for creating websites that could adapt their layouts to different devices.

Reference: https://www.w3.org/standards/

2014 — HTML5

HTML5 introduced a range of capabilities designed for modern Web applications, including new semantic elements and support for multimedia and interactive content.

HTML5 became an important stage in the evolution from document-oriented websites toward application-oriented Web experiences.

Reference: https://www.w3.org/TR/2014/REC-html5-20141028/

Today — The Modern Web

The modern Web combines technologies such as HTML, CSS, JavaScript, Web APIs, multimedia, and accessibility standards. Websites can now provide services that were previously associated mainly with desktop applications.

Web standards continue to evolve through organizations and communities working on interoperability, accessibility, security, and new capabilities.

Reference: https://www.w3.org/standards/

Conclusion

The World Wide Web has developed from a small information sharing project at CERN into a global platform for publishing, communication, applications, entertainment, education, and business.

The timeline shows how the Web progressed through several important stages: the original proposal, the first browser and server, the public release of the technology, the growth of browsers, the creation of Web standards, and the development of modern interactive websites.
